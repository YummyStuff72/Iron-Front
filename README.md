# Ironfront Command

A deliberately ambitious 3D browser RTS prototype.

## Run
Open `index.html` through a static web server (GitHub Pages works). The game imports Three.js from jsDelivr, so an internet connection is needed for the CDN dependency.

## Controls
- Left click: select
- Right click: move / attack
- Mouse wheel: zoom
- Drag: pan
- WASD / arrows: reserved for camera extension
- ESC: cancel building placement
- R: recruit rifleman

## Current systems
3D terrain, city construction, resources, population, unit recruitment, unit movement, combat, enemy reinforcements, enemy command post, victory/defeat, minimap, day/night indicator, and responsive HUD.
